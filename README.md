# Hello Kitty Matching Game

A fun and interactive memory matching game featuring Hello Kitty! Test your memory by matching pairs of Hello Kitty cards.

🎮 [Play the Game](https://rvale92.github.io/Hello-Kitty/)

## Features

- 4x4 grid of cards
- Card flip animations
- Match animations
- Sound effects
- Move counter
- Timer
- Responsive design
- Corner decorations

## How to Play

1. Click on any card to reveal the Hello Kitty image
2. Click on another card to find its match
3. If the cards match, they'll stay face up
4. If they don't match, they'll flip back over
5. Match all pairs to win the game!

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Animate.css for animations

## Installation

1. Clone this repository
2. Open index.html in your web browser
3. Start playing!
